# 遗响 / Echoes

中英双语互动叙事游戏。玩家将通过调查、对话、推理与回溯逐步揭开事件真相。

## 在线运行

本项目为纯静态网页，可直接部署到 GitHub Pages。打开 `index.html` 即可运行；游戏进度和笔记保存在浏览器本地存储中。

## 主要内容

- 中英双语切换
- 章节剧情、调查热点、证据推理与聊天交互
- 线索笔记、个人笔记、章节回溯与本地存档
- 针对 PC、平板、手机竖屏与横屏优化
- 7 张 WebP 场景插画，兼顾清晰度与加载速度

## 文件结构

- `index.html`：页面入口
- `style.css`：界面与响应式样式
- `story.js`：中文剧情数据
- `locales.en.js`：英文剧情数据
- `game.js`：游戏主逻辑
- `i18n.js`：语言切换
- `memory.js`：记忆与回溯功能
- `notebook.js`：线索及个人笔记功能
- `assets/`：WebP 场景图片
